# Release Notes

This page tracks changes across FastPubSub versions. For version compatibility guidelines, see [Versioning](versions.md).

## Version History

Release notes are automatically pulled from [GitHub Releases](https://github.com/matheusvnm/fastpubsub/releases).

!!! info "Latest Releases"
    Visit the [GitHub Releases page](https://github.com/matheusvnm/fastpubsub/releases) for the most up-to-date release information, including:

    - New features and improvements
    - Bug fixes
    - Breaking changes
    - Migration guides

## Upgrade Guide

When upgrading between versions:

1. **Read the release notes** for all versions between your current and target version
2. **Check for breaking changes** marked with `BREAKING`
3. **Update your code** following any migration guides
4. **Run your tests** to verify everything works
5. **Update your dependency** pin

## Reporting Issues

Found a bug or have a feature request?

- [Open an issue](https://github.com/matheusvnm/fastpubsub/issues/new) on GitHub
- Include your FastPubSub version, Python version, and steps to reproduce
