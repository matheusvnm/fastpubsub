# Advanced Usage

The main [User Guide](../tutorial/index.md) should be enough to give you a tour through all the main features of **FastPubSub**.
In the next sections you will see other options, configurations, and additional features.

Most of them are not necessarily "**advanced**" but other Google Pub/Sub tools you can use and this framework exposes.
It is likely that for your use case, the solution is one of them.

## You need the User Guide first

You could still use most of the features in **FastPubSub** with the knowledge from the main [User Guide](../tutorial/index.md).

If you still need further information, the next section will give you that divided by **Google Pub/Sub** and **FastPubSub** specific configuration.
However, we assume you already read the guide first and mastered those main ideas.
